HPLC 咖啡因檢量線與樣品定量

從 Shimadzu LCsolution 匯出檔建立檢量線、計算樣品咖啡因濃度， 並示範峰對齊（alignDE）與 airPLS 基線校正。R 與 Python 兩套獨立實作，結果一致。

入門入門版教學 從讀檔到算出濃度的最短路徑，適合第一次接觸 HPLC 定量。 進階進階版教學 判峰邏輯、檢量線診斷、峰對齊與基線校正的完整討論。 原始碼原始碼與資料 GitHub repo：R / Python 程式、10 個層析資料檔、分析輸出。

自己跑一遍

git clone https://github.com/Tai-ShengYeh/caffeine-hplc
cd caffeine-hplc
python caffeine_calibration.py     # 或 Rscript caffeine_calibration.R

峰對齊的部分需要 alignDE，請安裝 Tai-ShengYeh/alignDE （v3.0.1），不要安裝上游的 zmzhang/alignDE—— 那是 2012 年的 2.0.1，跑這份資料會出錯。
